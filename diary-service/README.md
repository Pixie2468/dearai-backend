# Diary Service

An internal FastAPI microservice responsible for persisting generated diary entries in PostgreSQL. It is not exposed to the public internet directly; all traffic is routed through the Gateway.

---

## Responsibilities

| Concern | Detail |
|---------|--------|
| **Diary Persistence** | Stores emotional diary entries generated by the Agent Service. |
| **HTTP API** | Provides REST endpoints for fetching past diary entries for the user. |
| **Auth** | Relies on the PASETO `X-Internal-Auth` token generated by the Go Gateway to authorize requests and securely identify the user (`user_id = sub`). |

---

## Architecture

- **Auth:** Decrypts the V4-local PASETO token injected by the Gateway.
- **Persistence:** Connects to PostgreSQL (`diary_db`). In production on GCP, it connects via Private Service Access (Private IP) to a Cloud SQL instance.
- **Routing:** Reached from the internet via `https://[GATEWAY_URL]/api/diary/*`. The Gateway proxies requests to this service.

---

## Configuration

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `DATABASE_URL` | **yes** | `postgresql://postgres:postgres@localhost:5432/postgres` | PostgreSQL connection string |
| `PASETO_SYMMETRIC_KEY` | **yes** | — | 64-char hex string (32 bytes). Must match the Gateway's key. |

### Example `.env`

```bash
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/diary_db
PASETO_SYMMETRIC_KEY=0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef
```

## Running Locally

To run the Diary Service natively:

```bash
# Install dependencies
uv sync

# Setup environment variables
cp .env.example .env

# Run the server
uv run uvicorn app.main:app --host 0.0.0.0 --port 8002
```

The service will be available at `http://localhost:8002`. You can view the OpenAPI interactive documentation at `http://localhost:8002/docs`.

To run via Docker:

```bash
docker build -t dearai-diary-service .
docker run --rm -p 8002:8000 --env-file .env dearai-diary-service
```
