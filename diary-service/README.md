# Diary Service

An internal microservice for persisting user diary entries in PostgreSQL.

## Overview
This service is a Python FastAPI application that handles HTTP requests proxy-forwarded by the Go Gateway. It uses SQLAlchemy and `psycopg2` to write user diary entries directly to a persistent Cloud SQL PostgreSQL database.

## Architecture
- **Auth:** Relies on a PASETO `X-Internal-Auth` token generated by the Go Gateway.
- **Persistence:** Connects to PostgreSQL (`diary_db`) via Private IP.
- **Port:** Listens on port 8002 locally or 8080 in Cloud Run.
- **Proxy Path:** Reached from the internet via `https://[GATEWAY_URL]/api/diary/*`

## Running Locally
```bash
uv run uvicorn app.main:app --host 0.0.0.0 --port 8002
```
