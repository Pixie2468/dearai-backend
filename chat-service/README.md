# Chat Service

An internal microservice for persisting chat history in PostgreSQL.

## Overview
This service is a Python FastAPI application that handles HTTP requests proxy-forwarded by the Go Gateway. It uses SQLAlchemy and `psycopg2` to write user interactions (from the AI Service) to a persistent Cloud SQL PostgreSQL database.

## Architecture
- **Auth:** Relies on a PASETO `X-Internal-Auth` token generated by the Go Gateway.
- **Persistence:** Connects to PostgreSQL (`chat_db`) via Private IP.
- **Port:** Listens on port 8001 locally or 8080 in Cloud Run.
- **Proxy Path:** Reached from the internet via `https://[GATEWAY_URL]/api/chat/*`

## Running Locally
```bash
uv run uvicorn app.main:app --host 0.0.0.0 --port 8001
```
